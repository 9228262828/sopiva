SOPIVA PRIVACY

Privacy Policy

Effective date: October 23, 2026

Summary: SOPIVA is an offline-first procedure checklist manager. The current core version does not require an account, Firebase, backend, cloud sync, ads, analytics, location, camera, microphone, contacts, or payment information.

1. Introduction

This Privacy Policy explains how SOPIVA, package com.sopiva.procedures, handles information in the current core version of the app.

2. Scope

This Policy applies to the SOPIVA mobile application and these informational support pages.

3. Offline-First Design

SOPIVA is designed as an offline-first procedure checklist and workflow organization tool.

4. No Account Required

You do not need to create a SOPIVA account, username, password, or public profile to use the current core version.

5. No Login Data

Because there is no login system in the current core version, SOPIVA does not request sign-in credentials.

6. Procedure Names

You may enter procedure names. These are stored locally on your device.

7. Procedure Descriptions

You may enter procedure descriptions or instructions. These are stored locally.

8. Procedure Categories

SOPIVA may store categories such as Operations, Admin, Client, Quality, Finance, Safety, or Other.

9. Favorites

SOPIVA may store whether a procedure is marked as a favorite.

10. Checklist Steps

You may create checklist steps for procedures. Step titles are stored locally.

11. Step Notes

You may enter optional notes or instructions for checklist steps. These are stored locally.

12. Step Order

SOPIVA may store the order of steps in a procedure so runs follow your configured sequence.

13. Run Records

When you complete a procedure run, SOPIVA may store a local run record.

14. Run Start and Finish Time

SOPIVA may store the start and finish time of a completed run for local history and timing calculations.

15. Run Duration

SOPIVA may store or calculate the duration of each completed run.

16. Run Notes

You may add an optional note when saving a completed run.

17. Completed Steps

SOPIVA may store whether each run step was completed.

18. Skipped Steps

SOPIVA may store whether a run step was skipped.

19. Pending Steps

During an active run, SOPIVA may temporarily track pending steps on your device.

20. Completion Rate

SOPIVA calculates completion percentages from locally stored run step outcomes.

21. Average Completion Rate

SOPIVA may calculate an average completion rate across your saved runs.

22. Average Run Time

SOPIVA may calculate average run duration from local run history.

23. Usage Counts

SOPIVA may calculate how many completed runs are associated with a procedure.

24. Most Used Procedures

SOPIVA may show your most used procedures based on locally stored run counts.

25. Category Statistics

SOPIVA may calculate the number of procedures in each category.

26. Completed Step Statistics

SOPIVA may calculate the total number of completed steps from local run history.

27. Skipped Step Statistics

SOPIVA may calculate the total number of skipped steps from local run history.

28. Search

Search terms used to find procedures or run-history records are processed locally and are not sent to a SOPIVA-operated server.

29. Filters

Category filters and other in-app filters are processed locally on your device.

30. Dark Mode Preference

Your dark-mode preference may be stored locally so SOPIVA can remember your appearance choice.

31. Local Storage

The current core version uses local application storage, such as SharedPreferences, for procedures, steps, run history, and preferences.

32. No Firebase

The current core version is not designed to use Firebase for authentication, databases, analytics, remote configuration, or cloud synchronization.

33. No Remote Backend

The current core version does not send your procedures or run history to a SOPIVA-operated backend.

34. No Cloud Sync

The current core version does not provide SOPIVA-operated cloud synchronization between devices.

35. No Advertising

The current core version does not contain SOPIVA-operated advertising.

36. No Personalized Ads

SOPIVA does not use your locally stored procedure information for personalized advertising in the current core version.

37. No Behavioral Analytics

The current core version is not designed to collect behavioral analytics for marketing or advertising.

38. No Cross-App Tracking

SOPIVA is not designed to track your activity across unrelated third-party apps or websites.

39. No Sale of Personal Information

SOPIVA does not intentionally sell or rent the locally stored information described in this Policy.

40. No Precise Location

The current core version does not require precise or approximate location permission.

41. No Camera

The current core version does not require camera access.

42. No Microphone

The current core version does not require microphone access or audio recording.

43. No Contacts

The current core version does not require access to your contacts.

44. No Phone or SMS

The current core version does not require phone-call, call-log, or SMS permissions.

45. No Calendar Permission

The current core version does not require access to your device calendar.

46. No Photos or Media

The current core version does not require access to your photo library, gallery, videos, or media library.

47. No General File Access

The current core version does not require broad access to personal documents or general device storage for normal use.

48. No Payment Information

The current core version does not require payment-card information, bank credentials, or payment account details.

49. No Purchases in Core Version

The current core version described by this Policy does not require an in-app purchase to use its core functionality.

50. No Public Profiles

The current core version does not include public user profiles.

51. No Social Feed

The current core version does not include a social feed or public posting system.

52. No User Messaging

The current core version does not include direct messaging or user-to-user chat.

53. No Collaboration Backend

The current core version does not synchronize procedures with coworkers, teams, or organizations through a SOPIVA-operated server.

54. No Procedure Sharing Service

The current core version does not publish or distribute your procedure content through a SOPIVA-operated sharing service.

55. No External Integrations

The current core version does not require integrations with workplace software, CRM systems, cloud drives, or external databases.

56. No Sensitive Data Requirement

SOPIVA does not require government identifiers, passwords, payment credentials, medical records, or other highly sensitive personal information for normal use.

57. Free-Text Safety

Because descriptions, step notes, and run notes are free text, avoid entering passwords, financial credentials, private keys, medical records, or other highly sensitive information.

58. Data Retention

Saved procedure information generally remains on your device until you delete it, reset local app data, clear application storage, uninstall the app, or the operating system removes the data.

59. Delete Procedures

You may delete procedures from SOPIVA. Existing completed run history may remain available unless separately deleted or all data is reset.

60. Delete Steps

You may delete checklist steps from a procedure.

61. Delete Run Records

You may delete individual completed run records from local history.

62. Reset All Data

SOPIVA includes a reset option that removes locally saved procedures, steps, run history, and related calculated statistics.

63. Uninstalling the App

Uninstalling SOPIVA may remove locally stored information, subject to operating-system or device backup and restore behavior.

64. Device Backups

Your operating system or device provider may back up application data according to your device settings. Such backups are not controlled by SOPIVA's core app logic.

65. Data Recovery

Because the current core version does not include SOPIVA-operated cloud backup, we may not be able to recover deleted procedure information or run history.

66. Device Security

You are responsible for protecting access to your device using available device security features.

67. Workplace Use

If you use SOPIVA for workplace procedures, you are responsible for ensuring the procedures are appropriate for your organization and role.

68. Safety-Critical Use

69. Legal and Regulatory Use

SOPIVA does not verify that a procedure complies with laws, regulations, standards, contracts, policies, or professional requirements.

70. Financial Procedures

If you use SOPIVA for finance-related procedures, you remain responsible for applicable controls, approvals, reconciliation, and compliance obligations.

71. Medical or Emergency Procedures

SOPIVA is not a medical device and should not replace medical protocols, clinical judgment, emergency instructions, or professional supervision.

72. Children

73. Third-Party Platforms
