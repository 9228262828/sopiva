SOPIVA — Procedure Checklist Manager
Tagline: Run every process the right way.
Package: com.sopiva.procedures

Add to pubspec.yaml:

dependencies:
  flutter:
    sdk: flutter
  shared_preferences: ^2.3.2

Included features:
- Splash Screen
- Professional Office Dashboard
- My Procedures
- Add / Edit / Delete Procedure
- Procedure Categories
- Favorites
- Search + Category Filters
- Procedure Details
- Add / Edit / Delete Checklist Steps
- Reorder Checklist Steps
- Start Procedure Run
- Complete / Undo Steps
- Skip / Unskip Steps
- Pause / Resume Run
- Live Run Progress
- Live Run Timer
- Run Notes
- Finished Run Summary
- Run History
- Per-Run Completed / Skipped Step Details
- Delete Run History Entry
- Total Procedures
- Total Runs
- Average Completion Rate
- Average Run Time
- Total Completed Steps
- Total Skipped Steps
- Most Used Procedures
- Procedures by Category
- Dark Mode
- Privacy Policy
- Terms & Conditions
- Reset All Data
- SharedPreferences JSON persistence

Architecture:
- Material 3
- ChangeNotifier + AnimatedBuilder
- SharedPreferences
- Offline-first

Not included:
- Firebase
- Backend
- Login / Accounts
- Ads
- Analytics
- Cloud Sync
- Sensitive permissions
- Required image/audio assets

Release package name:
com.sopiva.procedures
